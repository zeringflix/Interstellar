# RAGDOLL CRASH PHYSICS (Roblox game): start here

The Roblox game lives in [`ragdoll-crash-physics/`](ragdoll-crash-physics/) on branch `claude/ragdoll-crash-physics-research-j5nvbr`. It has nothing to do with the web project in the rest of this repository.

To put it into Roblox Studio, follow **[`ragdoll-crash-physics/INSTALL_WITH_CLAUDE_DESKTOP.md`](ragdoll-crash-physics/INSTALL_WITH_CLAUDE_DESKTOP.md)** step by step. It is written so another Claude agent, or a person, can do the whole install and verify it:
1. Download.
2. Open the place.
3. Import the 17 vehicle models.
4. Run the install check script until it prints `INSTALL OK`.
5. Set the game settings.
6. Add the Robux passes.
7. Play-test, including the first-person view.

What the game is: [`ragdoll-crash-physics/README.md`](ragdoll-crash-physics/README.md).
